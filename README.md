# SP Tak Gallery

Static mobile-first shot review interface for GitHub Pages.

## Safety boundary

- This repository contains demo media only.
- Original footage, secrets, render outputs, and internal SP Tak source code must not be copied here.
- Review decisions are stored in the current browser with `localStorage`.

## Files

- `index.html` - application shell
- `styles.css` - responsive visual system
- `app.js` - filtering, review state, preview, and export
- `assets/demo-products.png` - generated demo contact sheet

## GitHub Pages

Publish from the root of the `main` branch. The expected URL is:

`https://takza947-star.github.io/SP-Tak-Gallery/`
